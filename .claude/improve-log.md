## 2026-08-07 ／ 担当分野：志望校（AO_HOUR=1）

APP_VER: `2026.08.11-12` → `2026.08.07`
※ 直前まで実日付と合わない `2026.08.11-*` が使われていたため、当日の日付に戻しました。

### 出した5案
1. 出願締切が過ぎると志望校カードが全部グレーになり、試験日・合格発表までのカウントダウンが消える
2. `openSchool` の詳細で、試験日・合格発表に残り日数が出ない（出願締切だけ「あとN日」が付く）
3. 出願締切・必要書類が空だと逆算プランと書類チェックが黙って止まるのに、空欄の行は表示ごと消えるため気づけない
4. `vSchools` の検索が `(s.name+s.faculty+s.dept).includes(kw)`。未入力欄が `undefined` として連結され、ひらがな検索も効かない
5. `openSchool` の出願チェックリストが全校共通の10項目固定で、その大学の実際の必要書類（`docList`）を反映しない

### 入れた改善（1・2・3）
- **`schoolNextDate(s)` / `schoolDateBadge(s)` を新設**（`schoolProgress` の直後）。
  エントリー開始・出願締切・試験日・合格発表のうち、今日以降でいちばん近い日程を返す。
  `schoolCard` のバッジをこれに差し替え、締切が残っていれば従来どおり「締切まで◯日」、
  過ぎていれば「締切済 ＋ 試験まで◯日 / 合格発表まで◯日」に切り替わる。
  日付の実体は `title` 属性に入れた。14日以内=alert / 30日以内=warn / それ以外=navy は従来の配色を踏襲。
- **`openSchool` の日付行に残り日数**。ローカル関数 `dleft(iso)` を足し、
  エントリー開始・出願締切・試験日・合格発表の4行すべてに「（あとN日）」を付けた。
- **`openSchool` に未入力の案内**。`s.deadline`（`lastDeadline` も無い場合）と
  必要書類（`docList` / `docs`）が空のときだけ `note info` を出し、
  「この志望校を編集」ボタンから `editSchool(s.id)` へ飛べるようにした。両方埋まっていれば何も出ない。

### 見送った案
- **4（検索）**：`undefined` 連結は表示に出ず実害が小さい。ひらがな検索は
  オートコンプリート側（`fieldAutocomplete`）の仕組みを持ち込む必要があり、今回の分量に見合わない。次回以降の候補。
- **5（チェックリストの動的化）**：`s.checklist` のキーが固定10個である前提で
  `schoolProgress()` が % を出しているため、動的化すると既存ユーザーの進捗％が変わってしまう。
  データ構造の作り直しにあたるので選ばない。

### 検証
- `node tests/smoke.mjs` … 15 PASS / 0 FAIL
- `node tests/school-dates.mjs`（今回追加）… 15 PASS / 0 FAIL
  締切前／締切後・試験前／試験後・発表前／全日程終了／日付なし／締切だけ空 の7パターンと、
  詳細シートの残り日数、未入力案内の出し分け、日付項目が無い古いデータでの `openSchool` を確認。

### 次回への申し送り
- 志望校まわりで残っている候補：検索のひらがな対応（案4）、志望校リストの並び替え（締切が近い順）。

## 2026-08-07 ／ 担当分野：面接・小論文（AO_HOUR=17 → 17%7=3）

APP_VER: `2026.08.11-21` → `2026.08.07-6`

### 先に分かったこと（重要・次回への申し送り）
直前の `370fc2f Update index.html`（ご本人による手元ファイルの再アップロード）で、
同日の自動改善（`2026.08.07` 〜 `2026.08.07-5`）が index.html からまるごと消えていました。
`schoolNextDate` が存在せず、`tests/interview-essay.mjs` `tests/school-dates.mjs`
`tests/home-priority.mjs` `tests/home-dates.mjs` `tests/backup.mjs` が赤のまま残っていたのが根拠です。
意図的な取り消しではなく上書き事故と判断し、今回の担当分野（面接・小論文）ぶんは入れ直しました。
**担当外の赤（ホーム・志望校・設定）は今回は触っていません。それぞれの担当回で入れ直してください。**

### 出した5案
1. 面接練習で回答を書いても、✕・背景タップ・「ふりかえる」で別シートに移ると全部消える
2. 小論文で本文を書いても、✕ や「🤖 評価観点でチェック」（別シートに置きかわる）で全部消える
3. `openInterview` / `openEssay` のタイマーが `setInterval` のまま。閉じても止まらず、開き直すと二重に走る
4. 小論文の字数カウンターが `320/800字` だけ。オーバーしているのか、8割に届いていないのかが分からない
5. 自己評価（1〜4）を押しても `save()` されず、「練習を記録して保存」を押さない限り端末に残らない

### 入れた改善（1・2 ＋ その付随として 3・4・5）
- **`onSheetClose(fn)` / `runSheetClose(soft)` を新設**（`openSheet` の直前）。
  `openSheet` の先頭と `closeSheet` の先頭で呼ぶ。これで「✕」「背景タップ」「別シートへの置きかわり」の
  3経路すべてが同じ後始末を通る。`pagehide` / `visibilitychange(hidden)` では `soft=true` で呼び、
  保存だけ走らせて登録は消さない（＝戻ってきたときタイマーが動いたまま）。
- **面接練習の書きかけを保存**。`openInterview` に `onSheetClose` を登録し、
  閉じた時点の `ans.get()` を `q.answer` に入れて `save()`＋`render()`。変化が無ければ何もしない。
  あわせて `soft` でないときだけ `clearInterval(timerH)`（案3）、自己評価のタップに `save()`（案5）。
- **小論文の書きかけを保存**。`openEssay` に `persist()` を追加し、「保存」ボタンと `onSheetClose` で共用。
  何度呼んでも同じ答案を更新するだけ（`S.essays.indexOf(e)<0` のときだけ push）なので二重に増えない。
  新規で何も書いていなければ答案を作らない。
- **字数カウンター**（案4）。目安ありのときだけ、超過＝赤で「◯字オーバー」、8割以上＝緑で「あと◯字書けます」、
  8割未満＝「8割の◯字まであと◯字」。目安の入力欄にも `input` を張って、あとから入れてもすぐ反映。
  募集要項で確認するよう促す一文を下に添えた。
- **よくある質問**。追加した質問がシートを閉じたあとの一覧にすぐ出るよう、追加件数があれば `render()`。

### 見送った案
- なし（5案とも 1・2 を軸に低リスクでまとめて入れられたため、落とした案はありません）。

### 検証
- `node tests/smoke.mjs` … 15 PASS / 0 FAIL
- `node tests/interview-essay.mjs`（既存・上書きで赤くなっていたもの）… 24 PASS / 0 FAIL に復帰
- `node tests/sheet-close.mjs`（今回追加）… 23 PASS / 0 FAIL
  小論文のAIチェック経由で本文が残るか、開き直しても答案が増えないか、
  後始末が次のシートに持ち越されないか、pagehide では保存だけでタイマーが止まらないか、
  タスク編集・書類エディターなど他のシートが従来どおり動くか、古いデータで壊れないか。
- 変更前後で `backup` `home-dates` `home-priority` `school-dates` の結果は同一（＝今回の変更による後退なし）。

### 注意点
- `onSheetClose` はグローバルに1本。シートの中からさらにシートを開く画面（`confirmDelete`・AIシート）を
  足すときは、先に登録した後始末が走ることを前提に書くこと。
- 削除は `close()` → 後始末で保存 → `confirmDelete` → 実削除 の順。逆にすると消したものが復活する。
