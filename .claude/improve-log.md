## 2026-08-02 ／ 担当分野: タスク・締切（AO_HOUR=11 → 11%7=4）

### 入れた改善

**1. 自動でできた「緊急」書類タスクを、自分で直したり消したりできるようにした**

- 症状：`render()` のたびに `syncDocTasks()` が走り、`ex.due` と `ex.title` を無条件に上書きしていた。
  そのため `editTask` で日付や名前を変えて保存 → `commit()` → `render()` の流れで、
  保存した内容が**その場で元に戻っていた**。削除しても同じ流れで**すぐ作り直されて**いた。
- 直し方：
  - `blankState().meta` に `docTaskOff:{}` を追加。`migrate()` に型を保証する1行を足した（古いデータでも必ず入る）。
  - `docTaskOff(k)` / `docTaskIsOff(k)` / `detachDocTask(t)` を `syncDocTasks` の直前に追加。
  - `syncDocTasks()` の生成ループの先頭で `if(docTaskIsOff(k)) return;`。
  - `editTask()` の保存で、既存タスクなら `detachDocTask(t)`（`docauto=false` にして自動管理から外す）。
  - `editTask()` の削除で `docTaskOff(t.dkey)`。あわせて削除の確認文を、自動タスク用に分かりやすく変えた。
- さわっていないタスクの自動更新（締切が今日以降に保たれる／書類に着手すると消える）は元のまま。

**2. タスク一覧を「期限を過ぎた／未完了（日付ごと）／先の予定」に分けた**

- 症状：逆算プランを作ると `vTasks()` の未完了カードに最大90件がベタ並びになり、
  今日やる分が下に埋もれていた（デモ＋総仕上げプランで実測97件）。
- 直し方：
  - `vTasks()` を、期限超過の別カード（`data-tk="over"`）＋ 未完了カード（`data-tk="open"`）に分割。
  - `TASK_HORIZON=14`。14日以内は `appendTaskGroups()` で日付見出し（今日／明日／あとN日／期限なし）つきで表示。
    14日より先は `<details class="acc">` に畳む（見出しは `<span class="smt">` で包む決まりに従った）。
  - `syncTaskCounts()` に `over` を追加。`open` は期限超過分を引いた数に変更（表示と数字を合わせるため）。
  - 行そのもの（`taskRow` / `paintTaskRow` / `tapOK`）には一切手を入れていない。
    チェックしても `render()` は呼ばれず、行の高さも並び順も変わらない。

**3.（担当分野外・安全のため）古いiOS Safariで構文エラーになる書き方を除去**

- `?.`（オプショナルチェーン）が3か所あった。Safari 13.4 未満では**構文エラー＝アプリ全体が真っ白**になる。
  `index.html:2437` / `2606` / `4575` を素の書き方に置換。`4575` は `X?'':''` で両分岐とも `''` だったため `''` に。
- 禁止されているオブジェクトスプレッド `{...d}` が `index.html:2601` に1か所。`Object.assign` に置換。
