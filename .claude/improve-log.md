# 改善ログ

各回、AO_HOUR を 7 で割った余りで担当分野を決めて 1〜2 個だけ直しています。
同じ改善を繰り返さないよう、入れた案・見送った案の両方を残します。

## 2026-08-07 ／ 担当分野：志望校（AO_HOUR=1）

APP_VER: `2026.08.11-12` → `2026.08.07`
※ 直前まで実日付と合わない `2026.08.11-*` が使われていたため、当日の日付に戻しました。

### 出した5案
1. 出願締切が過ぎると志望校カードが全部グレーになり、試験日・合格発表までのカウントダウンが消える
2. `openSchool` の詳細で、試験日・合格発表に残り日数が出ない（出願締切だけ「あとN日」が付く）
3. 出願締切・必要書類が空だと逆算プランと書類チェックが黙って止まるのに、空欄の行は表示ごと消えるため気づけない
4. `vSchools` の検索が `(s.name+s.faculty+s.dept).includes(kw)`。未入力欄が `undefined` として連結され、ひらがな検索も効かない
5. `openSchool` の出願チェックリストが全校共通の10項目固定で、その大学の実際の必要書類（`docList`）を反映しない

### 入れた改善（1・2・3）
- **`schoolNextDate(s)` / `schoolDateBadge(s)` を新設**（`schoolProgress` の直後）。
  エントリー開始・出願締切・試験日・合格発表のうち、今日以降でいちばん近い日程を返す。
  `schoolCard` のバッジをこれに差し替え、締切が残っていれば従来どおり「締切まで◯日」、
  過ぎていれば「締切済 ＋ 試験まで◯日 / 合格発表まで◯日」に切り替わる。
  日付の実体は `title` 属性に入れた。14日以内=alert / 30日以内=warn / それ以外=navy は従来の配色を踏襲。
- **`openSchool` の日付行に残り日数**。ローカル関数 `dleft(iso)` を足し、
  エントリー開始・出願締切・試験日・合格発表の4行すべてに「（あとN日）」を付けた。
- **`openSchool` に未入力の案内**。`s.deadline`（`lastDeadline` も無い場合）と
  必要書類（`docList` / `docs`）が空のときだけ `note info` を出し、
  「この志望校を編集」ボタンから `editSchool(s.id)` へ飛べるようにした。両方埋まっていれば何も出ない。

### 見送った案
- **4（検索）**：`undefined` 連結は表示に出ず実害が小さい。ひらがな検索は
  オートコンプリート側（`fieldAutocomplete`）の仕組みを持ち込む必要があり、今回の分量に見合わない。次回以降の候補。
- **5（チェックリストの動的化）**：`s.checklist` のキーが固定10個である前提で
  `schoolProgress()` が % を出しているため、動的化すると既存ユーザーの進捗％が変わってしまう。
  データ構造の作り直しにあたるので選ばない。
