# 今回の更新（2026年8月8日）

今回は「提出書類」のページを見直しました。バージョンは **2026.08.08** です。

## 入れた改善

### 1. 書類の「志望校」を、あとから選べるようになりました
これがいちばん大きな変更です。これまで書類の志望校は、新しく作るときにしか選べませんでした。
そのため志望校を選ばずに作った書類は、たとえ1200字書いてあっても、
志望校ごとの「提出書類の取り組み状況」では「未登録」と表示され、
「まだ作っていません」という緊急タスクが消えないままでした
（アプリの別の画面には「編集タブで設定してください」と出るのに、その欄がありませんでした）。
これからは書類のエディターの「編集」タブに「志望校」の欄があり、あとからでも結びつけられます。
選んだ時点で取り組み状況が「作成中◯字」に変わり、余計な緊急タスクもその場で消えます。

### 2. 「この書類が、どの必要書類として数えられているか」が見えるようになりました
志望校の欄の下に、いまの状態が一行で出ます。
志望校が未設定なら「⚠️ 志望校が未設定です」と赤で出ます。
結びついていれば「見本大学の必要書類 志望理由書 として反映されます」と出ます。
どの必要書類にも当てはまっていないときは、その理由と、
「種別」かタイトルを書類名に合わせれば数えられるようになることをお知らせします。
これまでは、なぜ「未着手」と言われるのかが画面のどこにも出ていませんでした。

### 3. 文字数の制限を、あとから入れられるようになりました
募集要項をあとで見て「800字以内」と分かることはよくありますが、
これまで文字数制限は作成時にしか入れられず、あとから入れる場所がありませんでした。
そのため文字数はずっと「700 字」と出るだけで、超過の警告も一生出ませんでした。
これからは文字数の表示の右横に「制限 ◯◯ 字」の入力欄があり、いつでも入れ直せます。
空にすれば制限なしに戻ります。

### 4. 残りの字数が出るようになりました
文字数の表示が「700 / 800字（あと100字）」のように、あと何字書けるかまで出ます。
超えているときは「840 / 800字（40字 超過）」と赤で出ます。

### 5. 古いiPhoneでアプリが開かなくなる書き方を1か所直しました
「この下書きを複製」のボタンの中に、古いiPhoneのブラウザが読めない書き方が残っていました。
この書き方が1か所でもあると、そのiPhoneではアプリ全体が真っ白になってしまいます。
動きはまったく同じまま、古い機種でも読める書き方に直しました。
（複製の中身は今までどおりです。本文・志望校・文字数制限・メモは引き継ぎ、
バージョン履歴は引き継がず、先生からのコメントは別のものとしてコピーします。）

## 今回は見送ったこと

- **書類一覧のしぼりこみ**：志望校ごと・状態ごとに探せるようにする案です。
  一覧の並び順そのものを触ることになり、変更が大きくなるので今回はやめました。次回以降に回します。
- **タイトルと設問の編集**：これも「編集」タブでできると便利ですが、
  タイトルは画面の見出しと二か所で管理することになり、設問はAIに渡している文章でもあります。
  1回にたくさん詰め込まないほうが安全なので、次回に回しました。
- **取り組み状況に出す稿の選び方**：いま同じ種類の書類が複数あると、
  いちばん字数の多いものが進捗として表示されます。新しい稿を優先する案も考えましたが、
  「いちばん書けている稿を見せる」という今の考え方にも理由があり、
  すでにお使いの方の表示が変わってしまうので、変えないことにしました。
