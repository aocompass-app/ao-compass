# 今回の更新（2026年8月7日）

今回は「面接対策」と「小論文対策」のページを見直しました。バージョンは **2026.08.07-6** です。

## 入れた改善

### 1. 書いた回答・答案が、画面を閉じても消えなくなりました
これがいちばん大きな変更です。これまでは面接練習で回答を書いても、
右上の「×」を押したり、画面の外側をタップしたり、
「ふりかえる」ボタンを押して別の画面に移ったりすると、書いた内容がまるごと消えていました。
小論文も同じで、本文を800字書いたあとに「評価観点でチェック」を押すと、
チェックの画面に切りかわった時点で本文が失われていました。
これからは、どの閉じ方をしても、その時点の内容が自動で残ります。
スマホで別のアプリに切りかえたときや、ブラウザを閉じたときも同じです。
面接練習の「振り返り（自己評価）」の点数も、押した時点ですぐ残るようにしました。
※ 練習時間と改善メモだけは、これまでどおり「練習を記録して保存」を押したときに記録されます。

### 2. 小論文の文字数が「足りているか・多すぎるか」で出るようになりました
これまでは「320/800字」と数字が並ぶだけで、その字数でいいのかが分かりませんでした。
これからは、字数をオーバーすると赤い字で「100字オーバー」、
目安の8割を超えると緑の字で「あと20字書けます」、
8割に届いていなければ「8割の640字まであと320字」と出ます。
「◯字以内」の指定では8割以上書くのが一般的な目安なので、そこを基準にしています。
文字数の目安をあとから入力し直しても、その場ですぐ表示が切りかわります。
実際の字数指定は募集要項でご確認ください、という一文もそえてあります。

### 3. 練習中のタイマーが、閉じたあとも動きっぱなしにならないようにしました
面接練習・小論文のタイマーは、これまで画面を閉じても裏で動き続けていて、
もう一度開くと時間がずれていました。閉じたときにきちんと止まるようにしました。
ただし、スマホで一時的に別のアプリに移っただけのときは止めません。戻ってくると続きから進みます。

### 4. 「よくある質問」から追加した質問が、閉じたあとすぐ一覧に出るようにしました
これまでは追加しても、一覧に戻ったときに表示が古いままのことがありました。

## 今回は見送ったこと

まとめて直しました。1つ1つを別々に直すより、変更する箇所が少なくてすみ、安全でした。
