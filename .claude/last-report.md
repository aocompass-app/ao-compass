# 今回の更新（2026年8月8日）

今回も「提出書類」のページを見直しました。バージョンは **2026.08.08-4** です。

## 入れた改善

### 1. 書きかけの文章が、閉じたときに消えなくなりました
今回いちばん大事な直しです。書類の本文は、打つのをやめて少ししてから自動で保存される仕組みでした。
そのため「打ち終わった直後に、すぐ×ボタンや画面の外側をタップして閉じる」と、
最後に打った一文だけが保存されないまま消えることがありました。
これからは、閉じるときに必ず保存を確定させます。
タブを「AI分析」や「履歴」に切りかえるときも同じように、先に本文を保存してから切りかわります。

### 2. 書類のタイトルと設問を、あとから直せるようになりました
これまでタイトルと設問は、書類を新しく作るときにしか入れられませんでした。
でも募集要項を読んで設問の文言がわかるのは、たいてい書き始めたあとです。
また「第1稿」を「第2稿」に直したくても、直す場所がありませんでした。
これからは「編集」タブの中の **「📝 タイトル・設問を直す」** を開けば、いつでも書き直せます。
（ふだんは閉じているので、本文の入力欄が下に押し出されないようにしてあります。）

### 3. 前回お伝えした「タイトルを書類名に合わせてください」が、実際にできるようになりました
前回の更新で、書類が志望校の必要書類として数えられないときに
「種別かタイトルを書類名に合わせてください」という案内を出すようにしました。
ところが、そのタイトルを直す場所がアプリのどこにもありませんでした。今回それがつながりました。
たとえば「無題のメモ」を「見本大 志望理由書 第1稿」に直すと、
その場で「提出書類の取り組み状況」が「未登録」から「作成中◯字」に変わり、
「まだ作っていません」という緊急タスクも消えます。

### 4. 設問がその場で表示されるようになりました
設問を入れると、編集画面のいちばん上の青い枠にすぐ出ます（消せば枠も消えます）。
設問を入れておくと、AI分析が「その問いにちゃんと答えられているか」まで見てくれます。

## 今回は見送ったこと

- **書類一覧のしぼりこみ**：志望校ごと・状態ごとに探せるようにする案です。
  前回に続いて持ち越しました。今回はすでに「画面を閉じるときの動き」という
  アプリ全体に関わるところを直しているので、一度にいくつも重ねないほうが安全だと判断しました。
  次回の第一候補です。
- **取り組み状況に出す稿の選び方**：同じ種類の書類が複数あるとき、いまはいちばん字数の多いものが
  進捗として表示されます。新しい稿を優先する案もありますが、
  すでにお使いの方の表示が変わってしまうので、前回と同じく変えないことにしました。

## 確認したこと

基本動作の15項目と、今回のために新しく作った39項目を、すべて通しています。
前回作った37項目も通ったままです（1項目だけ、確かめ方をより厳しいものに書き直しました）。
設問もタイトルも入っていない古いデータでも、書類のエディターと全部の画面が開くことを確かめました。
タスク・新規作成・志望校など、書類以外の画面も開いて閉じられることを確かめています。
画面の横幅390ピクセル（ふつうのスマホ）で、横にはみ出さないことも実測しました。
入力したデータには一切手を加えていません。
